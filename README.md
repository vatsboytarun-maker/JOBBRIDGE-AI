# JOBBRIDGE AI

AI-assisted job discovery and application workflow focused on Facilities & Administration and Procurement & Commercial roles.

## Features
- Resume PDF keyword extraction
- Job search tickets
- Facilities & Administration default ticket
- Procurement & Commercial default ticket
- Custom keywords and locations
- Match scoring
- Greenhouse public job discovery
- Lever public job discovery
- Application tracker foundation
- English/Hindi mobile UI

## Project
- `mobile/` Flutter Android app
- `backend/` FastAPI local backend

Security challenges such as CAPTCHA, OTP and MFA are not bypassed. Application automation must use supported employer flows and comply with each site's rules.
